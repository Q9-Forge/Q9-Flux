Fix: CF write corruption for 256-byte RBF images

Problem:
- 256-byte RBF disk images (OS-9 standard) became corrupted after writes
- Read: correctly loaded TWO 256-byte sectors into 512-byte buffer
- Write: only wrote ONE 256-byte sector back → bytes 256-511 lost!
- Result: filesystem corruption, "Bad CRC" errors

Root Cause:
cb030_cf_store_sector() had asymmetric behavior compared to
cb030_cf_load_write_buffer():
- Read fills full 512-byte buffer from two image sectors
- Write only stored first 256 bytes → data loss

Solution:
Modified cb030_cf_store_sector() to write BOTH sectors for 256-byte images:
```c
if (img_sec < Q9_BOARD_CF_SECTOR_SIZE) {
    fwrite(b->cf_sector, 1, img_sec, b->cf_file);
    fseek(b->cf_file, (long)(b->cf_lba + 1u) * (long)img_sec, SEEK_SET);
    fwrite(b->cf_sector + img_sec, 1, Q9_BOARD_CF_SECTOR_SIZE - img_sec, b->cf_file);
}
```
